# Rubric: literature-review

## Correctness (1-5)
- 1: Fabricates citations, invents specific findings the user did not provide, misstates the meaning of "literature review" (e.g., claims it is a summary), or gives field-conventional advice that is wrong (e.g., recommends APA for a CS venue that uses numeric citations).
- 5: Every factual claim about literature-review conventions is correct and field-appropriate. Where the response would otherwise need a citation it does not have, it uses an explicit placeholder (`[CITATION NEEDED]`) rather than inventing one. Distinguishes correctly between narrative and systematic reviews when relevant.

## Completeness (1-5)
- 1: Skips the diagnosis of the corpus, jumps straight to a generic outline, or omits one of: organizational scheme + justification, synthesis (not summary), critical voice, gap statement. Doesn't ask for the corpus when one isn't provided.
- 5: Covers all `ideal_traits` for the scenario, asks for missing context (corpus, deliverable type, citation style) before drafting where appropriate, includes a defensible gap statement, and ends with a concrete ask of the user for the next iteration.

## Expert Alignment (1-5)
- 1: Treats the review as paper-by-paper summary, defaults to chronological structure without justification, avoids critical voice ("Smith found X. Jones found Y. Lin found Z."), or recommends including every paper "for completeness." Would be marked down by an experienced thesis advisor.
- 5: Concept-centric, synthesis-driven, with judicious critical voice woven throughout. Recommends thematic structure as the default and justifies departures from it. Treats gap identification as the review's payoff, not an afterthought. Tone matches a senior PhD student or junior advisor — not a Wikipedia article. Aligns with the matrix method (Galvan/Hart) and Webster & Watson's concept-centric framing.

## Actionability (1-5)
- 1: Vague advice ("organize your themes carefully", "add critical voice"), no concrete next step, no template the user can fill in, no specific asks back to the user. Student finishes reading and still doesn't know what to type next.
- 5: User can take the response and immediately (a) reply with their corpus or the requested missing detail, or (b) start writing/revising a specific section using the proposed outline and synthesis paragraph as scaffolding. Concrete sentence-level patterns where relevant. Markers like `[CITATION NEEDED]` make incomplete spots editable rather than hidden.

## Weighting guidance for judges

For this skill, **Expert Alignment** carries the most weight: the literature-review genre has strict conventions (concept-centric organization, synthesis vs. summary, critical voice, gap-as-payoff), and a response that violates them is wrong even if it sounds polished. **Correctness** is binary in practice — fabricated citations or summary-prose dressed up as synthesis should drop the overall score sharply regardless of how complete or actionable the rest is. **Completeness** and **Actionability** matter but are easier to recover; a response that asks the user for the corpus instead of drafting is fully complete for that turn even though the draft itself is missing.
